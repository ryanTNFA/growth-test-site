# The Growth Test has moved

The Growth Test now lives at **https://growthtest.thenewforeignassistance.org**, published by The New Foreign Assistance from
`The-New-Foreign-Assistance/growth-test`.

This repository used to serve it at https://ryantnfa.github.io/growth-test-site/. It now holds only two pages, `index.html` and
`404.html`, which forward every old link to the same page at the new address, with its query and its settings kept.

The earlier releases built here are kept: the tags `v0.2.0` and `v0.4.0` hold the sites as released, and their archived
copies stay on Zenodo.

Cite as: Moore, Ryan A., and The New Foreign Assistance, *The Growth Test*, https://doi.org/10.5281/zenodo.23924472 (the DOI
resolves to the latest release; each tagged release has its own).

The New Foreign Assistance (TNFA), 2026.
